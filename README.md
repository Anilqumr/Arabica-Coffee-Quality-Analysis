# Coffee Quality Analysis with Power BI 
This project analyzes coffee quality data from the Coffee Quality Institute (CQI) using Power BI. The goal is to uncover which factors influence coffee quality scores. 

## Project Contents 

- **Overview Document:** A detailed explanation of the business problem, objectives, and insights. 

- **Requirements Document:** Lists both functional and technical requirements for the analysis.
- **Dataset:** The raw coffee quality data used for all analysis (no personal info included).
- **Power BI File:** The .pbix file containing all calculations, visuals, and transformations.
- **Dashboard PDF:** A summarized snapshot of the final dashboard for quick reference.

## How to Use 
1. Open the Power BI file to interact with the dashboard. 
2. Refer to the overview and requirements documents for context and scope.
3. Use the dataset if you'd like to reproduce or expand the analysis. 

## Key Insights 
- Sensory attributes like balance, flavor, and acidity are the strongest predictors of coffee quality. 
- Country of origin and processing methods significantly affect cup scores.
- Defects and altitude also play a role in determining quality. 

## Technologies Used 
- Power BI for interactive dashboard development. 
- Power Query for data cleaning and transformation.
- Visualizations like scatter plots, bar charts, and key influencers.
